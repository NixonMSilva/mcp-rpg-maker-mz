# Specification

this repository. Local copies, when present, are `EVENT_SPEC.md` and `DATABASE_SPEC.md` (gitignored).

Public documentation of what is implemented:

- [docs/STATUS.md](docs/STATUS.md): milestones and design decisions
- [LIMITATIONS.md](LIMITATIONS.md): known limitations
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): code layout and write pipeline

- [docs/NATIVE_FORMATS.md](docs/NATIVE_FORMATS.md): verified RPG Maker MZ native formats
